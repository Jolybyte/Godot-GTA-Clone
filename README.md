# 🌆 НЕОН-СИТИ: мрачная осень

**GTA-like open-world 3D tech demo на Godot 4** — процедурный город, транспорт, полиция, миссии, рэгдолл и кинематографичная графика. Весь контент генерируется кодом: игра работает «из коробки», без единого внешнего ассета, но охотно подхватывает ваши текстуры, модели и звуки.

## ✨ Возможности

###  Мир
- **Процедурная генерация города**: кварталы, здания с окнами/неоном/крышами, парк, дом игрока, тротуары, деревья, уличные пропы (мусорки, гидранты, лавки…).
- **Дорожная сеть**: осевая штриховая разметка, кромочные линии, зебры и стоп-линии (один `MultiMesh` = 1 draw call), **светофоры с фазами** — трафик реально стоит на красный и стоит в очереди.
- **Трафик**: ~60 машин с ИИ (маршруты, повороты на перекрёстках, пробки, «терпеливое» ожидание у светофора), ~55 припаркованных, водители в кабинах.
- **~300 пешеходов**: ходьба по тротуарам, разговоры, паника от выстрелов; бандиты нейтральны, пока их не тронешь; полиция спавнится по уровню розыска.
- **Цикл дня и ночи**: солнце, луна, туман, уличные фонари (ближайшие 8 — реальные источники света), фары и стоп-сигналы.
- **Осень**: падающие и опавшие листья, мокрый асфальт, лужи с отражениями (SSR).
- **Динамический спавн**: дальние пешеходы и машины незаметно переносятся ближе к игроку.

### 🚶 Игрок
- Ходьба/бег/прыжок пешком и **аркадное вождение** с дрейфом и ручником.
- **Угон на ходу**: водитель выбрасывается из машины и убегает.
- **10 видов оружия**: кулаки / нож / бита · пистолет / УЗИ / дробовик / автомат / снайперка · граната / гранатомёт.
- Прицеливание (ПКМ), перезарядка, разброс с отдачей, хедшоты ×3.
- **Рэгдолл**: от пуль и ударов тело отлетает целиком, расчленёнка — только от взрывов.
- **Розыск до 5★**: пешие копы арестовывают в упор, патрульные машины таранят, с 2★ полиция стреляет; розыск гаснет со временем или в доме игрока.
- **Миссии с катсценами**: доставка, зачистка, гонка на время, сбор, подрыв, контракт, погоня.
- **Дом игрока**: лечит и сбрасывает розыск.

### 🎥 Графика (Forward+)
- SSAO, SSR, SDFGI, объёмный туман, bloom, TAA + FXAA, автоэкспозиция, ACES.
- Кино-постобработка: моушен-блюр, резкость, split-tone, S-кривая, виньетка, плёночное зерно, хроматические аберрации.
- Процедурные PBR-текстуры (albedo / normal / roughness / emissive) через `TexGen`, если нет своих.

### 🔊 Звук
- Автоскан ваших файлов в `res://assets/audio/`: эмбиенты (день/ночь/салон — кроссфейд), выстрелы по типам оружия, взрывы, сирена, движок…
- Процедурные фолбэки (синтез `AudioStreamWAV`): движок, сирена, взрывы, шаги, краши, UI.
- Шины `Master` (компрессор) / `SFX` / `AMBIENT` / `MUSIC`, 3D-позиционирование взрывов и выстрелов NPC.

## 📁 Структура проекта

```
res://
├── autoload/
│   └── game.gd            # синглтон Game: состояние, константы, сигналы, хелперы, реестр модулей
├── modules/
│   ├── asset_loader.gd    # скан текстур/моделей из res://assets
│   ├── tex_gen.gd         # процедурные PBR-текстуры (class_name TexGen)
│   ├── city_builder.gd    # город: здания, дороги, разметка, светофоры, фонари, пропы
│   ├── day_night.gd       # окружение: солнце/луна, туман, SSAO/SSR/SDFGI, фары
│   ├── player_controller.gd # игрок, камера, вход/выход из машины
│   ├── weapon_system.gd   # оружие, стрельба, перезарядка, прицел
│   ├── combat.gd          # урон, взрывы, рэгдолл, снаряды, эффекты
│   ├── vehicle_manager.gd # машины, трафик, физика, светофорное поведение
│   ├── ped_manager.gd     # пешеходы, бандиты, водители
│   ├── police_manager.gd  # розыск, пешие копы, патрули
│   ├── mission_manager.gd # миссии и катсцены
│   ├── audio_manager.gd   # звук: файлы пользователя + процедурные фолбэки
│   └── hud_manager.gd     # HUD, миникарта, экраны, пост-шейдер
└── scenes/
    └── main.tscn / main.gd # сборка и связывание модулей
```

Модули не знают друг о друге напрямую — общаются через синглтон `Game` (состояние + сигналы + реестр).

## 📦 Свои ассеты (опционально)

Игра полностью играбельна без ассетов, но подхватит ваши:

```
res://assets/
├── textures/   facade_*.png, road.png, sidewalk.png, grass.png   (PBR: albedo/normal/roughness)
├── models/     tree.glb, bench.glb, trash.glb, dumpster.glb, hydrant.glb, barrier.glb, crate.glb, lamp.glb
└── audio/      ambient_day/night.ogg, shot_pistol/uzi/shotgun/rifle/sniper.ogg,
                explosion_*.ogg, siren_loop.ogg, engine_loop.ogg, reload/melee/horn/step/crash/ui.ogg, music_*.ogg
```

Имена файлов определяют категорию автоматически; несколько файлов в категории = случайный выбор при срабатывании.

## 🚀 Запуск

1. Установите **Godot 4.7+**.
2. Склонируйте репозиторий и откройте `project.godot`.
3. Убедитесь, что рендерер — **Forward+** (`Project Settings → Rendering`).
4. `F5` — играть.

## 🧠 Технические детали

- **Коллизии** — ручные (circle vs AABB / circle vs circle): физический движок не участвует в движении, всё детерминированно и дёшево.
- **Стрельба** — ray-sphere по пешеходам/машинам/пропам + трассеры; зона попадания (голова/руки/ноги) определяет отрыв конечности при взрыве.
- **Разметка и светофоры** — по одному `MultiMesh` на тип (~3000 и ~500 инстансов, 1 draw call каждый); цвета ламп — instance colors.
- **LOD пешеходов**: дальше 55 м — один бокс вместо скелетной фигуры.
